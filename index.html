ResumeForge AI

An ATS-aware resume optimizer — not another "AI rewrites your resume" tool.

REPO public ↗ DEMO not deployed
Drag-and-drop PDF/DOCX upload Deterministic 0–100 ATS score Missing-keyword detection AI internship tailoring One-click improved-resume PDF
React 18 TypeScript Tailwind CSS FastAPI OpenAI GPT-4o-mini SQLite PyMuPDF FPDF2
architecture
React + TS (Vite) → FastAPI → OpenAI GPT-4o-mini → FPDF2 export

Not deployed yet — clone the repo and run it locally in a couple of minutes (setup steps in the README). Frontend deploys to Vercel, backend to Render, independently, once hosted.

Parses an uploaded PDF/DOCX resume, runs it through a deterministic 10-category ATS scoring engine, and cross-references it against a target job or internship description to surface missing keywords — before GPT ever gets involved. Once the gaps are clear, GPT-4o-mini generates tailored improvement suggestions and can rewrite sections to match a specific internship posting, exportable as a polished PDF. Upload → text extraction → rule-based scoring → keyword-gap analysis → OpenAI-powered suggestions → SQLite persistence → PDF export, with frontend and backend fully decoupled behind a REST API.
  • Keeping the ATS score deterministic and explainable rather than a black-box model call — the scoring logic runs independently of OpenAI, which is layered on top only for suggestions and tailoring, so a 74/100 means the same thing on every run.
  • Reliably parsing resume formatting — tables, multi-column layouts, icons — across PDF and DOCX without losing section structure.
  • Designing prompts that tailor a resume to a job description without inventing experience the candidate doesn't have.
  • Batch-tailor one resume against several job descriptions at once.
  • Browser extension to pull a job description straight from a posting.
  • Version history so students can compare resume drafts side-by-side.

AI Study Assistant

One workflow for turning lecture slides into summaries, quizzes, flashcards, and a revision plan.

REPO public ↗ DEMO not deployed
PDF / PPT / DOCX upload Auto-generated quizzes & flashcards Formula sheets & structured notes Day-by-day revision plan Chat directly with your notes
React 18 TypeScript Tailwind CSS FastAPI OpenAI GPT-4o-mini SQLite python-pptx
architecture
React + TS (Vite) → FastAPI → 10 prompt chains → SQLite sessions

Not deployed yet — clone the repo and run it locally in a couple of minutes (setup steps in the README). Ships to Vercel (frontend) + Render (backend) the same way as ResumeForge.

Students upload a PDF, PPT, or DOCX and get structured notes, a formula sheet, flagged important points, an auto-generated quiz, flip-style flashcards, likely interview questions, and a day-by-day revision plan — plus a chat interface to ask questions directly against their own material instead of a generic chatbot. Upload → text extraction (PyMuPDF for PDFs, python-pptx for slides, python-docx for Word) → per-feature OpenAI prompt chains → SQLite-backed sessions so results persist across visits and power the document Q&A chat.
  • Nine distinct generation modes off one uploaded document meant designing prompts that stay grounded in the source material instead of drifting into generic textbook answers — especially risky for auto-generated quizzes, where a wrong-but-plausible question is worse than no question.
  • Keeping response latency reasonable when a student requests several artifacts (notes + quiz + flashcards) back to back.
  • Extracting clean text from slide decks with inconsistent formatting without losing which points belonged to which slide.
  • Spaced-repetition scheduling for flashcards instead of a flat revision plan.
  • Multi-document sessions that combine a whole course's slides.
  • Export notes and flashcards to Anki or Notion.
